Privacy Policy

Last updated: September 2, 2026

Summary: Age Android does not collect or upload user data. Encryption and decryption run locally on your device.

1. Data collection

Age Android does not collect identity information, device identifiers, location, analytics, usage events, or crash reports.

2. Local storage and private keys

  • Public keys, non-secret metadata, and operation history are stored in the app-private Room database.
  • Private keys are encrypted with an AES-256-GCM wrapping key held by Android Keystore, then stored separately in noBackupFilesDir. Room never stores private-key plaintext.
  • Settings are stored in app-private DataStore; outputs go only to the location you choose or the app's local default folders.
  • Temporary and incomplete outputs are removed after completion, failure, or cancellation.

Private keys are intentionally not restored to another device. After a backup restore or Keystore invalidation, affected entries safely become public-key-only records.

3. Network access

Files, passphrases, private keys, and history are never uploaded. Network access is used only when you explicitly check for a GitHub Release or download an APK update.

4. Sensitive actions

Viewing, copying, or exporting a private key requires strong biometrics or the device credential. Normal local encryption and decryption do not add an extra authentication prompt.

5. Cryptography

Age Android uses the age format, including scrypt passphrases, classic X25519 recipients, and default hybrid ML-KEM-768 + X25519 recipients.

6. Third parties

The app contains no advertising, analytics, cloud key storage, file upload, or third-party crash reporting SDK.

7. Contact

Questions can be filed at github.com/vikiea/age_android.
