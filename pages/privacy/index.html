隐私政策

最后更新日期：2026 年 9 月 2 日

简要说明：Age Android 不收集、不传输、不存储任何用户数据。所有加密和解密操作均在您的设备本地完成。

1. 数据收集

Age Android 不收集任何个人信息，包括但不限于：

  • 姓名、邮箱、电话号码等身份信息
  • 设备标识符、IMEI、广告 ID
  • 位置信息
  • 使用行为和分析数据
  • 崩溃报告

2. 数据存储

所有数据均存储在您的设备本地：

  • 公钥与元数据：存储在应用私有的 Room 数据库中
  • 私钥：由 Android Keystore 中的 AES-256-GCM 密钥加密后，单独存储在应用的 noBackupFilesDir；Room 不保存私钥明文
  • 设置信息：存储在应用私有的 DataStore 中
  • 加密文件：输出到您选择的目录或应用默认目录
  • 临时文件：处理过程中创建，完成后自动清理

私钥不会通过 Android 备份跨设备自动恢复。恢复备份或设备密钥失效时，相关记录会安全降级为仅公钥记录；应用不会误报仍持有私钥。

3. 数据传输

Age Android 不会通过网络上传您的文件、密钥、密码或操作历史。应用更新检查仅访问公开的 GitHub Release 元数据和 APK 下载地址。

4. 权限使用

应用仅请求完成本地加解密所需的权限：

  • 存储访问（SAF）：用于读取待加密文件和写入加密输出文件
  • 网络访问：用于检查 GitHub Release 更新和下载 APK，不用于上传用户文件或隐私数据

5. 第三方服务

Age Android 不集成广告网络、统计分析 SDK 或第三方崩溃收集服务。

6. 加密算法

本应用使用 age 加密工具，采用以下算法：

  • X25519：非对称密钥交换
  • ML-KEM-768 + X25519：默认生成的后量子混合 recipient
  • ChaCha20-Poly1305：对称加密
  • scrypt：密码派生函数

7. 儿童隐私

本应用不针对 13 岁以下儿童，也不会有意收集儿童的个人信息。

8. 隐私政策变更

如隐私政策发生变更，我们将在本页面更新“最后更新日期”。建议您定期查看本页面。
