What it does

A mobile workbench for private files.

Age Android pairs Jetpack Compose with a local Go age engine, configurable Liquid Glass accents, and clean tree views so large file work stays streamed, visible, and under your control.

01

Batch encryption

Pack selected files and subfolders into tar or tar.gz; selected folders can be encrypted as standalone archive units.

02

Archive-aware decrypt

Decrypt .age files and restore packed content as a readable file tree in the chosen output directory.

03

Local key management

Generate, import, view, and use X25519 age key pairs without sending secret material off device.

04

Operation history

Review completed encryption and decryption work with status, paths, and tree-structured file details.

Android-native flow

Pick files, choose a secret, let the stream finish.

The app uses Android's storage access framework, Compose surfaces, bottom navigation, and local app storage instead of a remote upload flow.

  • ✓Subfolders stay as independent units, encrypt as one archive in separate mode, and results are shown as trees.
  • ✓Compression, duplicate handling, theme colors, and concurrency live in Settings.
  • ✓Share intents route incoming files directly to encrypt or decrypt workflows.

Local privacy boundary

Files, passphrases, private keys, and history stay on this device.

Age Android does not collect analytics, upload files, or transmit keys. The app uses Android storage access only for files you choose.
