# Age Android v5.0.0

Age Android 5 brings the Android app in line with Age Mac 1.5.0 while retaining Android-native folder selection, share intents, custom output folders, APK updates, and optional donation links.

## Highlights

- Hybrid ML-KEM-768 + X25519 post-quantum keys are generated by default; classic X25519 remains available explicitly.
- Generic age recipient and identity parsing accepts `age1pq1`, `AGE-SECRET-KEY-PQ-1`, and existing X25519 formats.
- Private keys are wrapped by an Android Keystore AES-256-GCM key and stored outside Room in `noBackupFilesDir`.
- Revealing, copying, or exporting a private key requires strong biometrics or the device credential.
- Long tar, gzip, encryption, decryption, and Android file-copy work can be cancelled with temporary and incomplete output cleanup.
- History records authentication type, safe key hints, compression, duplicate policy, concurrency, output trees, and cancellation.
- The interface now uses Material 3 adaptive navigation with restrained Backdrop glass, dynamic color, solid fallback, English, and Simplified Chinese.
- In-app updates select an ABI-specific APK with Universal fallback, then verify both the GitHub SHA-256 digest and the signing certificate.

Private keys are intentionally excluded from Android backup. If an app backup is restored to another device, entries whose protected secret is unavailable safely become public-key-only records.

## 中文说明

- 默认生成 ML-KEM-768 + X25519 后量子混合密钥，并保留经典 X25519 选项。
- 私钥使用 Android Keystore AES-256-GCM 包装密钥加密，Room 不保存私钥明文。
- 查看、复制和导出私钥前需要强生物识别或设备凭据认证。
- tar、gzip、加解密和 Android 文件复制支持取消，并清理临时及未完成输出。
- 历史详情新增认证方式、安全密钥提示、压缩、重名策略、并发数、输出树和取消状态。
- 使用 Material 3 自适应导航、克制的 Backdrop 玻璃效果、系统动态色和实色回退，并支持 English / 简体中文。
- 应用内更新按 ABI 选择 APK，并校验 GitHub SHA-256 摘要和相同签名证书。

私钥不会随 Android 备份跨设备自动恢复。恢复后缺少受保护私钥的记录会安全降级为仅公钥记录。
